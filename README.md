# Match 3 with animals

В рамках проекта реализована классическая игровая механика «Match-3» с анималистическим визуальным стилем, системой бонусов и поддержкой нескольких режимов сложности.

---

## 📝 Описание проекта
Игра представляет собой мобильное приложение для платформы Android. Игрок взаимодействует с сеткой игрового поля размером 9x14, заполненной фишками в виде различных животных. 

Ваша задача - переставлять соседние фишки местами так, чтобы собирать горизонтальные или вертикальные ряды из трех и более одинаковых элементов для получения игровых очков.

**Основные особенности:**
* Наличие двух режимов игры: обычного и с органичением времени
* Механика «падающих» фишек и автоматическое заполнение пустых ячеек новыми элементами.
* Умная система проверки всего поля на комбинации после падения.
* Полностью динамическая генерация игрового поля на старте без начальных совпадений.

## 🛠 Технологии и фишки проекта
Проект разработан на базе современных инструментов игровой индустрии:
* **Игровой движок:** Unity.
* **Язык программирования:** C# (основные скрипты: `_Board.cs`, `_InteractionWithAnimals.cs`, `MainMenuController.cs`).
* **Интерфейс (UI):** Unity UI (Canvas, RectTransform) и TextMeshPro для адаптивного отображения текста на экранах мобильных телефонов.
* **Архитектурные решения:** * Активное использование **корутин (IEnumerator)** для плавного перемещения фишек, задержек при падении и цикличного спавна бонусов.
* **Хранение данных** (`PlayerPrefs`) для передачи выбранного режима сложности между сценами и сохранения рекордов.
* **Спавн бонуснх фишек каждые 10 секунд** * Чтобы игроку не было скучно, каждые 10 секунд одна из обычных фишек на поле превращается в бонусную.
* **Уничтожение крестом** * Если игрок составляет комбинацию, в которой участвует бонусная фишка, происходит уничтожение фишек веркильного и горизонтального столбцов, в которых стоит бонусная фишка.

## 🚀 Характерные особенности и уникальность

### Режимы сложности
В игре реализовано два режима:
1. **Обычный:** Игра идет без ограничения по времени. Цель — набрать 5000 очков. При достижении этой отметки счетчик циклически сбрасывается. Режим отлично подходит для расслабленной игры.
2. **Режим на время:** Игроку дается ровно 60 секунд. Каждое совпадение приносит очки. При завершении времени открывается окно «Game Over» с фиксацией рекорда.

### Уникальные механики и бонусы
* **Каждые 10 секунд** на поле случайным образом генерируется **бонусная фишка**.
* При сборе комбинации с участием бонусной фишки происходит **уничтожение всего вертикального ряда и горизонтальной строки**, в кторой стоит бонусная фишка, принося игроку сразу 70 очков.

### Трудности, с которыми пришлось столкнуться:
* **Проблема «Зависания» во время паузы:** При остановке времени через `Time.timeScale = 0` обычные таймеры перестают работать, но корутины также могут вести себя непредсказуемо. Проблема была решена жесткой проверкой флага `IsPaused` в методах выбора фишек, что заблокировало любые действия игрока во время паузы.
* **Исключение комбинаций при старте:** Чтобы игрок не получал очки за случайные совпадения при первой генерации поля, был написан алгоритм `CoincidencesNearby`, который проверяет соседей слева и снизу прямо в процессе создания объектов и перебирает индексы до тех пор, пока ряд не станет уникальным.
* **Проверка поля после удаления комбинаций и генерации новых фишек:** После удаления комбинации и дозаполнении новыми фишками, на поле могли оставаться уже собранные комбинации, которые не удалялись сами и могли сбить игрока с толку. Для решения этой проблемы была написнаа функция 'CheckingTheEntieBoard' для проверки всего поля на комбинации после генерации новых фишек.
* **Плохая видимость бонусных фишек:** При генерации бонусных фишек их было трудно распознать на поле, а хотелось бы, чтобы игрок мог видеть их сразу после генерации. Для решения на каждую бонусную фишку был добавлен компонент 'Outline' с обводкой розового цвета.

## ⚙️ Техническое описание и запуск

### Системные требования
* **Операционная система:** Android 5.1 (API level 22 — Lollipop) или выше.
* **Процессор (CPU):** 4-ядерный процессор с тактовой частотой от 1.5 ГГц (архитектура ARMv7 или ARM64).
* **Оперативная память (RAM):** 2 ГБ.
* **Свободное место на диске:** Не менее 80 МБ (для установки APK-файла и хранения кэша PlayerPrefs).

### Как запустить проект на смартфоне:
1. Откройте предосталвенную ссылку на GitHub в браузере вашего смартфона на базе Andriod.
2. На главной странице репозитория прокрутите немного вниз и в правой колонке найдите раздел **Releases**. Кликните по самому верхнему релизу.
3. В нижней части раздела релиза найдите блок **Assets (Вложения)**.
4. Нажмите на файл **match1_3.apk**. Начнется автоматическое скачивание файла в память телефона.
5. После завершения загрузки нажмите кнопку **"Открыть"** во всплывающем окне (или найдите скачанный файл в папке **"Загрузки"** через Проводник телефона).
**Готово! Приятной игры!**
